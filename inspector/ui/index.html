Agentic Memory inspection host

The host is running and its local JSON API is available on this origin. The Sigma inspection dashboard that renders these routes is implemented by AMEM-11 and replaces this placeholder page.

  • GET /api/graph — the most recent completed graph view
  • GET /api/notes/:id — one complete current note
  • POST /api/search — a real memory search
  • POST /api/refresh — one paginated inspection refresh
  • POST /api/projection/rebuild — a fresh projection fit
  • POST /api/compare — stored-vector cosine similarity

See docs/dashboard.md for the contract of every route.
